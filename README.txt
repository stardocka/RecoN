RecoN

Description:
    RecoN automatically retrieves the visible content of a webpage (titles and paragraphs only), cleans and normalizes the text, removes noise, and generates a frequency‑based wordlist.
    It is designed to produce context‑relevant wordlists for OSINT, password profiling, or content analysis.

Features:
    Extracts only <h1>–<h4> and <p> elements

    Cleans HTML noise, punctuation, and duplicate whitespace

    Normalizes words (lowercasing, punctuation removal, apostrophe handling)

    Counts occurrences of each word

    Outputs a sorted list (ascending or descending frequency)
